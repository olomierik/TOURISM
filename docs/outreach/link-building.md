## 5. Medium and LinkedIn (republishing)

Republish approved posts with "Originally published on ExploreTanzania.online" and a link to the original. On Medium, use its import tool, which sets the canonical link to the original.

## 6. Reddit and Quora

Answer questions people actually asked about safari costs, parks, Zanzibar or car hire. Answer them in full in the reply itself, and link only where the page adds something the answer can't (for example the price table). Follow each subreddit's rules on self-promotion, and say plainly that you run the site.

Draft answers are written in chat per question, never in advance.
